# 轻谱 · 功能谱与现场曲单

面向手机、平板和电脑的本地功能谱工作台，用于写谱、排练和现场看谱。和弦、数字级数、罗马级数、歌词与可选简谱共用一份歌曲数据。

## 当前版本：谱库与写谱两个入口（2026-10-10）

默认进入谱库，底部只有 **谱库 / 写谱** 两个入口。谱库点开歌曲直接进入看谱 / 演出，写谱页内可以切换到同一首歌的阅读状态。顶部保留智能导入、导出和更多功能，分类与曲单折叠到一处。

| 入口 | 用途 |
| --- | --- |
| 谱库 | 大号智能导入入口、搜索、收藏、分类、排序、演出曲单和回收站；点歌直接看谱 |
| 写谱 | 点按编辑歌曲、段落、小节、和弦、歌词、简谱；页内切换看谱 / 演出 |

歌词可以逐字拖动。点字打开 100%–300% 的对齐面板，修改文字、字号、对应音符与坐标；可移到另一小节，或开启整小节自由放置，移到和弦和简谱区域。音符位置、音高与时值也可单独调整，位置变化不改变播放时值。

## 已接通的能力

- **制谱**：歌名、作者、大小调、变调夹、拍号、BPM、段落、小节、和弦、斜杠低音、拍数、歌词、旋律简谱、文字块、整体转调、撤销 / 重做与自动保存。
- **空白起稿**：新建与首次写谱从空白开始，不预填歌名、作者、调号、变调夹、速度或拍号，不自动加入示例段落；已有曲谱和导入信息保留。未填写的信息不出现在成品谱头。
- **和弦图**：复用 SVGuitar + chords-db，搜索 420 种和弦、1,634 个指法，支持等音与已收录的斜杠和弦、多把位、单图 60–180 px 大小、前后排列、移除和本曲和弦批量配图。原生 SVG 随谱保存，在看谱和 A4 输出中一致渲染，可单独下载 SVG。
- **AI 导入**：新版提示词输出 v2 JSON，包含连续小节编号、逐字音符对应、反复与结尾信息。多个代码块可以一起粘贴，或追加到当前歌曲，并继续粘贴下一批。旧版 v1 仍可读取。复制固定识谱提示词，把谱图交给豆包、GPT、Claude 等外部 AI；粘贴返回内容，校验标题 / 段落 / 小节与问题后确认导入。支持工程 JSON、固定 JSON 外壳中的 ChordPro / ChordMark / ABC，以及直接粘贴谱文。提示词全文可展开阅读；未导入的草稿在本次页面会话保留。
- **反复**：反复起止、2–8 次反复、第一 / 第二结尾会用于真正的播放次序，支持跨段落的基本反复；嵌套反复明确拒绝。
- **演出**：视觉提示可选灯点、屏幕边缘、当前小节或全屏背景；颜色与强度可调，支持静音视觉节拍。自动分页在边界前显示拍数倒数；缓慢跟随推进谱面。手动翻页会接管自动跟随，可点“回到当前拍”继续。只有和弦歌词的练习估算节奏需要明确开启自动翻谱。
- **练习**：Tone.js 播放和弦、旋律、节拍器与循环，支持长音 / 分解 / 扫弦伴奏、按段落试听、暂停与继续。
- **输出**：A4 竖版 PDF、逐页 PNG、浏览器打印、可编辑工程 JSON、ChordPro / ABC 文本。按实际渲染高度减少每页谱行，大字号时保持整行分页；单行超过 A4 高度会提示调整。
- **管理**：收藏、文件夹、标签、演出曲单排序、回收站恢复、整库备份与合并恢复。重复 ID 会生成副本并映射分类与曲单，保留已有歌曲。
- **外观**：浅绿、纸黄、白蓝、黑白、纯白五套主题；无衬线 / 衬线 / 等宽三档系统字体；整体字号、歌词与和弦比例独立设置；可隐藏歌词、歌曲信息、备注、小节号，并开启紧凑排版。界面字体与谱面字体分开，PDF 跟随谱面字体和比例。

## 本地运行

```bash
npm install
npm run dev -- --host
```

打开终端显示的地址。当前开发预览使用 `http://localhost:5173/`。

```bash
npm test
npm run build
npm audit --audit-level=high
```

生产交付物位于 `dist/`，可部署到静态托管。运行期不依赖在线 CDN。

## 数据与备份

免登录，无服务器、数据库、账号或云同步。歌曲写入当前浏览器 localStorage，键为 `chord-chart-workbench/v1/library`；换设备需使用“更多 → 备份与恢复”。工程 JSON 用于单首曲谱，整库 JSON 包含曲谱、收藏、文件夹、标签、曲单与回收站。浏览器清理网站数据会清除本地谱库，应保存下载的备份文件。

歌曲结构为 `schemaVersion: 3`，兼容旧版 v1 / v2。编辑通过现有 `store` 和音乐核心提交；写谱、看谱、演出与 A4 输出读取同一份歌曲。

## 已复用的开源资源

Tonal 用于音乐运算，ChordMark / converters 用于和弦谱文，abcjs 用于 ABC 主旋律解析，JianpuRender 用于简谱 SVG，Tone.js 用于试听与节拍调度，SVGuitar / chords-db 用于和弦指法，Lucide 用于图标，html-to-image / jsPDF 用于导出，Vite 用于开发和构建。此次 UI 改版未增加新的运行时依赖。

## 使用边界

图片识别由外部 AI 完成；轻谱负责谱文解析、校验、排版和修订。ABC 以单声部主旋律为目标，嵌套反复、D.S. / D.C.、多声部、途中变拍 / 变调需拆分核对或会被拒绝。没有原谱节奏时的自动翻谱按练习估算推进；暂停、改速和重复段会影响现场进度，应先排练。

PDF / PNG 是可打印的图片页，PDF 文字不能搜索。全屏和屏幕常亮由浏览器能力决定，设备不支持时仍可使用演出页面。可安装入口已提供 manifest，尚未提供离线缓存与云同步。
