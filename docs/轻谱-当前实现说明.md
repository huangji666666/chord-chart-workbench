# 轻谱当前实现说明

轻谱是一个本地优先的功能谱网页应用。谱库写在当前浏览器的 localStorage 里，歌曲不上传服务器；AI 识谱采用“外部多模态 AI 输出固定谱文，轻谱负责校验和排版”的轻量路线。

## 使用方式

在项目目录运行：

```bash
npm install
npm run dev -- --host
```

然后打开 Vite 输出的本地地址。生产交付物是 `npm run build` 生成的 `dist/` 目录，可放到任意静态托管。

## 产品入口（2026-10-10 第二轮）

默认进入谱库，底部只有谱库与写谱。谱库提供大号智能导入入口，点开歌曲直接看谱 / 演出；写谱页内切换写谱与看谱 / 演出。搜索、收藏、排序、文件夹、标签、曲单、回收站与备份保留，分类和曲单使用折叠区域。

顶部为智能导入、导出和更多功能。写谱保留歌曲信息、段落、小节、和弦 / 级数、歌词、简谱、撤销重做和高级编辑。更多里保留追加谱页、原有输出、管理、练习与演出设置。

## 字、音符与位置校正

点按歌词打开逐字与简谱对齐面板，100%–300% 放大。可以拖动字与音符，输入百分比坐标精调，改变单字字号与歌词行高度，选择对应音符、拆成单字、添加 / 删除字，并移动到另一小节。音高与时值可单独修改；总时值不匹配时拒绝保存。

默认把字放在歌词区域；勾选“允许移到和弦、简谱区域”后，可以在整个小节里自由放置，保存后也可在谱面直接拖动。原有自由文字块继续可拖动，共用 Pointer Events，并已修复拖动时文字中心点偏移的问题。

数据保存在每小节的可选 `alignment` 字段：`words` 保存字、位置、字号与零起始音符下标，`notes` 保存音符的视觉位置，`height` 保存歌词区高度。自由字的坐标相对于整小节，普通字相对于歌词区；音符相对于简谱行。JSON 工程、备份、复制与转调保留这些信息。歌词与简谱共享横向坐标，JianpuRender 保留时值线、八度点、升降号与长音延长线。

外观设置支持独立隐藏歌词、调拍信息、演奏备注、小节编号，并开启紧凑排版。显示开关不删除音乐数据，导出遵循当前显示设置。修复了范围滑块初始化时可能显示错误最小值的问题，包括字号与试听音量。

## 多页智能导入

推荐使用应用里复制的 v2 提示词，完整版本见 [AI 识谱提示词 v2](AI识谱提示词-v2-多页逐字.md)。JSON 包含 ABC 谱文、连续 `measures.number`、逐字 `syllables`、反复起止与第一 / 第二结尾。音符对应序号从 1 开始，休止也占序号；无法确认的字使用未对应状态并提示核对。没有旋律时只用带和弦的休止占位，导入后移除占位旋律，并保留歌词和练习节奏提示。

一次可以粘贴多份代码块或相邻 JSON，也可以选择多份谱文文件。编号完整时按小节号排序合并，检查谱文小节数、连续编号与音符引用；重复和缺号会拒绝。选择追加时核对当前歌曲的歌名、调号、拍号、变调夹和下一原谱小节号，追加可撤销。保存后继续下一批会更新提示词中的起始编号。普通已有谱文也能追加，旧版 v1 JSON、ChordPro、ChordMark、ABC 和工程文件保持兼容。

## 看谱与演出

反复起止、2–8 次反复、第一 / 第二结尾参与播放次序，支持跨段落的基本反复。嵌套反复明确拒绝；D.S. / D.C. 等复杂跳转需先展开或拆分核对。谱面、音频调度与视觉节拍使用同一歌曲。

演出保留手动分页、节拍自动分页和缓慢跟随，边界前 1–4 拍倒数、手动接管与恢复，灯点 / 边缘 / 当前小节 / 全屏视觉节拍、颜色、强度和静音设置。估算练习节奏需主动开启自动翻谱。全屏和常亮取决于浏览器支持。

A4 输出复用 `chart.js` 与 `melody.js`，位置和字号保留。按实际高度分页，不截断整行；导出页小节号连续。浏览器打印关闭后回到原入口。PDF / PNG 为图片页，工程 JSON 用于完整编辑恢复。

## 已复用的开源资源

### 空白起稿与 SVG 和弦图（2026-10-10）

首次使用、新建曲谱与首次进入写谱使用空白草稿；不自动插入歌名、作者、调号、拍号、速度、变调夹或示例段落。现有歌曲不重置，导入歌曲直接带入识别信息。底部写谱会返回本次编辑的歌曲，首次写谱优先复用已有空白草稿；从看谱页切到写谱编辑当前歌曲。

数据使用可选 `unsetMeta` 记录未填写的 `title / key / bpm / timeSignature`。标题实际为空字符串；音乐编辑内核仍保留计算调拍和速度的默认值，它们不是用户确认的元信息。所有表单、谱头、谱库和 ChordPro 导出按 `unsetMeta` 判断；级数与整体转调要求先设置调号，试听要求填写速度，旋律 ABC 导出要求确认调拍。原有数据没有此字段，继续按已填写的信息读取。

谱面工具栏的和弦图面板复用已安装的 SVGuitar 和 chords-db，没有新增运行时依赖。实际兼容的数据库为 420 种和弦、1,634 个指法；搜索支持等音与库中存在的斜杠和弦。缺少准确指法时提示未收录，不把斜杠和弦偷偷替换为根位和弦。每张图保存 `chord / position / size`，可以挑把位、缩放到 60–180 px、前后换序、删除或单独下载 SVG；本曲用到的和弦可以批量加入且不重复插入。

和弦图位于谱头与段落之间，颜色随主题，手机自动换行。工程、备份、复制、撤销重做均保留图形参数；整体转调同时改动图形和弦，并重选转调后第一把位。SVG 异步加载在屏幕布局测量、打印、A4 分页与导出前等待完成。独立图形文件为原生矢量 SVG，整页 PDF 仍为高清图片页。

这一轮使用 GitHub API 核查了两个上游仓库，均为 MIT；来源链接和许可证仍见下表。新增源码备份为 `.verify/before-blank-chord-diagrams-2026-10-10.zip`，真实截图在 `design/implemented-chord-diagrams/`；导出的 A4 PDF、SVG、工程 JSON 与渲染检查保存在 `.verify/chord-diagrams/`。

## 验证结果

- 351 条自动化测试通过，生产构建通过，依赖审计为 0 vulnerabilities。
- 新增验证：八个元信息字段全空、部分填写不确认其他字段、原有歌曲保留、空白工程往返；数据库等音 / 斜杠查找与部分横按；图形缩放、排序、保存重开、复制、撤销和转调；390px 手机及 768px 平板无横向溢出。实际下载 SVG、工程 JSON 和 A4 PDF，并渲染确认三个指法图及歌词完整、未设置调拍与速度不印出默认值。
- 实际浏览器验证：390px 手机、768px 平板和桌面；两个入口，谱库打开歌曲直达演出；多份倒序代码块合并、继续追加、重复页拒绝、新版提示词复制；实际拖动单字、字与音符位置保存、文字 / 字号修改、对应关系、跨小节移动、整小节自由放置；精简显示、长音与逐字像素对齐。
- 实际下载并渲染检查 A4 PDF：自定义字位置、音符、反复记号、四拍长音及整小节自由字。下载的工程文件再解析验证自由字坐标、字号、音符位置与对应关系。
- 截图在 `design/implemented-two-pages/`；源码备份在 `.verify/before-two-pages-alignment-2026-10-10.zip`。临时验证歌曲已移入可恢复的回收站，原有歌曲保留。

## 使用边界

识谱准确度仍由外部 AI 决定；轻谱负责检查与手动校正。ABC 目前以单声部、固定调拍为目标，复杂嵌套反复、多声部及途中变调 / 变拍需要拆分。没有原谱节奏的试听与翻谱会使用明确标记的练习节奏。
